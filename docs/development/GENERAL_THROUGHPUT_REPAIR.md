# General throughput and cancellation repair

The diagnosed session spent over eleven minutes paused after cancelling an unfilled
Floral Gelatin buy. Hypixel's full refund receipt does not name the item, so the old
notice filter rejected it and the verified-gone order could not resume after restart.
The pause display also named the first retained item instead of the failed trade.

Generic buy refunds are now accepted only during an intended zero-fill cancellation,
with known purchase price, zero previous holdings, and a whole-escrow amount matching
within server rounding. The proof is persisted; fresh order absence and inventory
checks remain required before repricing or release. Partial claims, other refunds,
unrelated income, absent orders without receipts and unknown basis do not qualify.
Legacy journals without this proof still need reconciliation; no missing order is
silently assumed refunded. Failure reporting retains the actual blocked item.

General buy orders now wait for the selected batch unless outbid/reprice conditions,
existing holdings or order timeout require a partial exit. Previously the first
claimable units cancelled every remainder, increasing GUI work and shrinking batches.

The calculator recommended configured Fuming Potato Book at roughly 6.2m/h while
legacy ranking bought Floral Gelatin. Fresh, configured GENERAL forecasts now rank
independently validated candidates with the exact same batch. Unconfigured routes,
quantity mismatches and stale reports cannot promote a candidate. Existing allowlists,
price/margin/volume filters, fresh quotes, budget reservations and confirmation checks
continue to determine eligibility; ordinary ranking remains the fallback. This is a
limited integration for general selection, not activation of the full shared queue.

Dashboard measured profit/hour is separate from a single opportunity's modeled rate.
It requires complete known-profit settlements and a minute of tracked active time;
pauses are excluded and unknown basis remains unknown. Sale diagnostics now include
known cost and actual profit for future performance investigation.

A 20m/h result is not established by this repair. The log's slow book cycles occupied
about 25m of a 35m cap. Candidate rates such as Fine Flour ~8.2m/h are individual,
conditional forecasts; capital constraints, menu contention, actual fills and market
changes prevent simply adding them into guaranteed portfolio earnings.
